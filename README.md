# 루루루: 인프런 연속 재생

Chrome에서 로컬로 실행하는 인프런 강좌 재생 확장 프로그램입니다. 여러 강좌를 대기열에 넣으면 한 탭에서 차례로 재생하고, **인프런 화면에 표시된 수업·퀴즈·미션 완료 여부**를 확인해 다음 강좌로 넘어갑니다. 일반 인프런과 `biz.inflearn.com` 강의실을 지원합니다.

> 실제 계정에서 영상·자료 수업·객관식 퀴즈의 자동 진행을 확인했습니다. 모든 강좌의 100% 완료를 보장하지는 않습니다. 사이트가 완료 상태를 보여 주지 않거나 직접 해야 하는 단계가 있으면 `확인 필요`로 멈춥니다. [실제 Chrome 검증 범위](LIVE-TEST.md)

## 설치

Chrome 120 이상과 Node.js 22.18 이상이 필요합니다. 이 저장소를 이미 받은 경우 첫 두 명령은 건너뛰세요.

```sh
git clone https://github.com/leetaesk/inflearn-rururu.git
cd inflearn-rururu
npm ci
npm run build
```

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 저장소 안에 생성된 **`dist` 폴더**를 선택합니다. 저장소 루트나 `src` 폴더를 선택하면 안 됩니다.
4. Chrome 도구 모음의 확장 프로그램 메뉴에서 **루루루**를 고정하고 아이콘을 누릅니다. 별도 대기열 화면이 열립니다.

Chrome의 [압축해제 확장 프로그램 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)를 참고할 수도 있습니다. Chrome 웹 스토어 설치판은 제공하지 않습니다.

## 처음 재생하기

1. **로그인:** 강의를 볼 Chrome 프로필에서 인프런에 로그인합니다. 대기열의 **인프런 로그인** 버튼은 [인프런 공식 로그인 페이지](https://www.inflearn.com/signin)를 엽니다. 확장 프로그램에 아이디나 비밀번호를 입력하지 않습니다.
2. **주소 가져오기:** 인프런의 **내 학습**에서 수강 가능한 강좌를 열고, 실제 강의실 주소를 Chrome 주소창에서 복사합니다. 강좌 제목을 주소로 직접 만들지 마세요. 잘못 만든 `courseSlug` 주소는 404로 이동할 수 있습니다.
3. **대기열에 추가:** 대기열 화면 오른쪽 **강좌 또는 강의실 주소** 칸에 주소를 한 줄에 하나씩 붙여넣고 **대기열에 추가**를 누릅니다. 강좌 탭을 이미 열어 두었다면 **열린 탭 가져오기**를 눌러도 됩니다. 강좌 행의 **위로/아래로**로 순서를 바꿀 수 있습니다.
4. **설정 저장:** 필요한 재생 속도, 음소거, 자료 수업, 퀴즈, 미션 방식을 선택하고 **설정 저장**을 누릅니다. 저장하지 않은 변경은 재생에 적용되지 않습니다.
5. **재생:** **대기열 재생**을 누릅니다. 강의실 탭 하나가 열리고 첫 미완료 수업부터 진행합니다. Chrome과 그 재생 탭은 열어 두세요. 대기열 화면은 닫아도 됩니다.

주소는 `https://www.inflearn.com` 또는 `https://biz.inflearn.com`의 강좌 소개·강의실 링크를 받습니다. 가장 확실한 것은 **실제로 열리는 강의실 URL을 그대로 복사**하는 것입니다. 예를 들어 `.../courses/lecture?courseId=12345&unitId=67890`처럼 `courseId`가 있는 주소나 `.../course/강좌-슬러그/dashboard?cid=12345` 같은 강좌 소개 주소를 사용할 수 있습니다. 주소 여러 개를 한 번에 추가할 때는 최대 200개입니다. 같은 식별자의 중복은 건너뜁니다.

## 재생 중 조작과 완료 확인

- 대기열의 **지금 재생**에는 강좌명, 현재 수업, 영상 시간과 상태가 표시됩니다. **재생 탭 보기**로 강의실을 확인할 수 있습니다.
- **일시정지** 후 **이어 재생**으로 다시 시작할 수 있습니다. 브라우저를 재시작하거나 재생 탭을 닫은 뒤에도 대기열은 남지만, 재생은 직접 다시 눌러야 합니다.
- 강좌 행의 **위로/아래로**는 재생 순서를 바꿉니다. 진행 중인 강좌의 주소 수정·삭제는 재생을 멈춘 뒤 할 수 있습니다.
- **완료 확인**은 인프런이 표시하는 수업 완료 수가 전체 수업 수와 같고, 퀴즈·미션도 완료됐을 때만 붙습니다. 반올림된 진도율 `100%`나 영상 종료만으로 완료 처리하지 않습니다. 수료증 발급은 별도 조건입니다.
- 진행할 수 없는 강좌는 **이 강좌 보류**로 넘길 수 있습니다. 보류한 강좌는 완료로 기록되지 않습니다. 다시 시도할 때는 해당 행의 **다시 대기**를 누릅니다.

## 재생 설정

| 설정 | 기본값 | 동작 |
| --- | --- | --- |
| 재생 속도 | 1배속 | 1·1.25·1.5·1.75·2배속 중 선택 |
| 음소거로 재생 | 켜짐 | 소리 있는 자동 재생이 차단될 수 있어 기본으로 켭니다. |
| 재생 중 화면 절전 방지 | 켜짐 | 재생 중 화면 절전을 막습니다. 노트북 덮개 닫기나 강제 잠자기는 막지 못합니다. |
| 영상 없는 자료 수업 | 멈추고 직접 확인 | 자동 확인을 선택하면 65~600초 기다린 뒤 화면의 ‘봤어요’를 누릅니다. |
| 객관식 퀴즈 | 자동 제출하고 오답 재시도 | 화면에 표시된 정오답을 기억해 인프런이 허용한 횟수 안에서 재시도합니다. 첫 시도는 틀릴 수 있고, 제출 완료가 100점을 뜻하지는 않습니다. |
| 미션 | 저장된 원고 자동 제출 | 이미 임시 저장된 제목·본문만 제출합니다. 원고 작성, 필수 첨부, 강사 승인까지 자동화하지 않습니다. |

## 멈췄을 때

| 화면 상태 | 할 일 |
| --- | --- |
| **로그인 필요** | **인프런 로그인**을 눌러 공식 페이지에서 로그인한 뒤 대기열로 돌아와 **이어 재생**을 누릅니다. |
| **강의실 주소를 찾지 못함(404)** | 강좌 행의 **주소 수정**에 실제 강의실 URL을 붙여넣고 **주소 저장 → 이어 재생**을 누릅니다. 정확한 URL도 404라면 내 학습에서 수강 권한을 확인합니다. |
| **자동 재생 차단** | 강의실에서 재생 버튼을 한 번 누르거나 확장의 **음소거로 재생**을 켭니다. |
| **영상은 끝났는데 완료가 안 됨** | 인프런 목차의 완료 표시와 ‘봤어요’ 버튼을 확인합니다. 사이트가 완료를 표시하기 전에는 다음 강좌로 넘기지 않습니다. |
| **퀴즈·미션 확인 필요** | 재생 탭에서 남은 문항·원고·첨부·검토 상태를 확인합니다. 해결 후 **이어 재생**을 누릅니다. |

## 업데이트

재생 중이라면 먼저 **일시정지**를 누릅니다. 저장소에서 아래 명령을 실행한 뒤 `chrome://extensions`에서 **루루루 카드의 새로고침 버튼**을 누르세요. 대기열은 로컬에 남으며, 업데이트 후 **이어 재생**으로 다시 시작합니다.

```sh
git pull
npm ci
npm run build
```

## 동작 원칙과 한계

이미 완료된 수업은 건너뛰고, 미완료 영상은 끝까지 재생한 뒤 인프런의 진도 반영을 기다립니다. 필요한 경우 화면의 ‘봤어요’를 누릅니다. 퀴즈는 선행 수업을 마친 뒤 진행하고, 선택지가 섞여도 표시된 정오답을 내용별로 기억합니다. 라이브 수업과 원고·첨부가 없는 미션은 직접 처리해야 합니다.

진도 API를 직접 호출하거나 재생 위치를 끝으로 이동하지 않습니다. 실제 플레이어와 화면의 버튼을 사용하며, ‘봤어요’는 최소 65초 간격으로 누릅니다. 영상이 90초간 멈추거나 재생 탭이 2분간 응답하지 않는 경우 확인을 요청합니다. 사이트가 완료로 표시하지 않은 퀴즈·미션은 완료로 간주하지 않습니다.

## 방식 비교와 선택 근거

| 방식 | 이 작업에서의 장점 | 비용·제약 |
| --- | --- | --- |
| Chrome 확장 프로그램 | 기존 로그인 상태 활용, 대기열 UI, 로컬 저장, 한 탭 순차 재생 | 처음 한 번 수동 설치, 사이트 DOM 변경에 대응 필요 |
| Playwright 헤드리스 실행기 | 자동화 테스트와 별도 환경에 적합 | 로그인 프로필 관리, 브라우저 설치, 보호된 플레이어·자동 재생 호환성 확인 필요 |
| 사용자 스크립트 | 작은 다음 버튼 자동화에 간단 | 별도 스크립트 관리자 필요, 여러 강좌 대기열·설정 관리 추가 구현 필요 |

이 사용 방식에는 확장 프로그램을 선택했습니다. 헤드리스 Chromium은 분리된 테스트 환경에서 사용합니다.

공식 문서 및 조사 자료 (2026-09-22 확인):

- [Chrome 콘텐츠 스크립트](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts): 페이지 DOM을 읽고 조작하는 격리된 실행 환경.
- [확장 서비스 워커 수명](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle): 워커는 종료될 수 있으므로 대기열을 `storage.local`에 저장.
- [Chrome 자동 재생 정책](https://developer.chrome.com/blog/autoplay): 음소거 기본값과 재생 거부 처리의 근거.
- [Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms), [power](https://developer.chrome.com/docs/extensions/reference/api/power): 응답 감시와 재생 중 절전 방지.
- [Playwright 확장 테스트](https://playwright.dev/docs/chrome-extensions): 확장이 설치된 별도 Chromium 프로필로 검증.
- [인프런 강사의 진도율 답변](https://www.inflearn.com/community/questions/1818379/진도율): 영상 끝까지 재생 및 일부 수업의 ‘봤어요’ 확인 안내. 인프런 운영팀의 정책 문서는 아닙니다.
- [인프런 공개 강의실](https://www.inflearn.com/course/lecture?courseSlug=virtualization-개발-환경-구축-가이드&unitId=242465)의 배포 JavaScript와 로그인된 강의실에서 목차, 영상 하단 버튼, 진도율 분수, 퀴즈 생성·선택·제출 화면을 확인했습니다.

## 개발과 검증

```sh
npm run check
npm test
npx playwright install chromium
npm run test:e2e
```

E2E는 임시 프로필에서 확장을 설치하고, 인프런 도메인 요청을 테스트용 강의실로 대체합니다. 실제 사용자 계정이나 수강 기록에 접근하지 않습니다. 테스트용 2초 WebM은 `tests/fixtures/lesson.webm`입니다. 실제 미디어의 `play`/`ended`와 확장 메시징·저장소를 사용합니다.

검증 항목: 구형 주소 전환, 비즈 도메인 유지, 두 강좌 순차 재생, 65초 자료 대기, 완료 미반영, 정지·재개, 탭 종료, 보류·재시도, 선택지가 섞이는 퀴즈의 오답 교정, 미션 제출과 검토 대기 구분, 두 테마의 접근성과 320~1280px 배치. [antislop Delivery Gate와 화면 증거](anti-slop/delivery-gate-2026-09-22.md).

- `src/adapter.ts`: 공개 강의실 DOM과 상호작용. 사이트 변경 시 우선 점검할 파일.
- `src/content.ts`: 재생·완료 대기·다음 수업 이동.
- `src/assessments.ts`: 퀴즈 자동 제출·오답 교정·미션 원고 제출.
- `src/background.ts`: 대기열·단일 탭 소유권·영속 저장·응답 감시.
- `src/dashboard.ts`, `public/dashboard.*`: 강좌 목록과 설정.

## 권한과 데이터

`storage`는 대기열·설정·최근 100개 기록·최대 2,000개 퀴즈 정오답 기록, `alarms`는 응답 감시, `power`는 재생 중 절전 방지에 사용합니다. 호스트 권한은 `inflearn.com`, `www.inflearn.com`, `biz.inflearn.com`에 한정합니다. 페이지 URL·제목·진도와 퀴즈 피드백을 로컬에 저장하며 별도 서버, 원격 실행 코드, 쿠키·비밀번호 접근은 사용하지 않습니다.

iframe 안의 별도 출처 플레이어, DRM에 따른 재생 불가, 숨겨진 완료 정보, 사이트 개편에는 추가 대응이 필요할 수 있습니다. 자동화가 정보를 읽지 못하면 완료로 처리하지 않고 확인을 요청합니다.
