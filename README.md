# 루루루: 인프런 연속 재생

Chrome에서 사용하는 로컬 Manifest V3 확장 프로그램입니다. 강좌 주소 여러 개를 대기열에 추가하면 하나의 재생 탭에서 미완료 수업을 순서대로 재생하고, 인프런의 완료 수업 수를 확인한 뒤 다음 강좌로 이동합니다.

일반 인프런과 `biz.inflearn.com` 강의실을 지원합니다. 실제 계정에서 자료 자동 확인, 첫 퀴즈 100점, 다음 영상 자동 전환까지 확인했습니다. 전체 대기열이 100%에 도달한 상태는 아니며, 재생 중에는 강좌별 실제 수업·퀴즈 진도를 표시합니다. 대상 5개 강좌와 확인 범위는 [실제 Chrome 검증 기록](LIVE-TEST.md)에 정리했습니다.

## 설치

빌드 결과가 이미 있으면 2번부터 진행합니다.

1. Node.js 22.18 이상에서 실행합니다.

   ```sh
   npm ci
   npm run build
   ```

2. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 저장소의 **dist** 폴더를 선택합니다.

   `dist` 폴더는 위 빌드 명령을 실행한 저장소 안에 생성됩니다.

4. 확장 프로그램 목록에서 루루루를 고정하고 아이콘을 누릅니다.

## 사용

- 대기열의 **인프런 로그인**을 누르면 [인프런 공식 로그인 페이지](https://www.inflearn.com/signin)가 열립니다. 로그인 정보는 확장 프로그램에 입력하지 않습니다.
- 강좌 소개 주소 또는 강의실 주소를 한 줄에 하나씩 추가합니다. 열린 강좌 탭을 가져올 수도 있습니다.
- 다른 인프런 강의실의 중복 재생을 정리한 뒤 **대기열 재생**을 누릅니다.
- 재생 탭과 Chrome을 켜 둡니다. 대기열 화면은 닫아도 됩니다.
- 일시정지하거나 탭이 닫혀도 대기열은 남습니다. **이어 재생**으로 다시 시작합니다.
- 로그인 화면으로 이동해 멈춘 경우 공식 페이지에서 로그인한 뒤 대기열의 **이어 재생**을 누릅니다. 중단된 강좌를 다시 엽니다.
- 404로 멈추면 강좌 행의 **주소 수정**에서 실제 강의실 주소를 입력해 저장하고 **이어 재생**을 누릅니다. 주소가 맞아도 수강 권한이 없으면 인프런에서 수강 가능 여부를 확인해야 합니다.
- 막힌 강좌는 **이 강좌 보류**로 남기고 다음 강좌를 진행할 수 있습니다. 보류는 완료로 기록되지 않습니다.

지원 주소 형식:

```text
https://www.inflearn.com/course/강좌-슬러그
https://www.inflearn.com/course/lecture?courseSlug=강좌-슬러그&unitId=수업번호
https://www.inflearn.com/courses/lecture?courseId=강좌번호&unitId=수업번호
https://biz.inflearn.com/courses/lecture?courseId=강좌번호&unitId=수업번호
```

한 번에 200개 주소를 추가할 수 있습니다. 같은 식별자의 중복 주소는 제외합니다. 숫자 ID 주소와 슬러그 주소를 섞으면 같은 강좌가 처음에는 별개로 인식될 수 있으므로 같은 형식의 주소를 권장합니다.

## 동작

- 기본 1배속·음소거 재생. 1~2배속과 소리 설정을 제공합니다.
- 영상을 끝까지 재생합니다. 사이트가 이미 완료로 표시한 수업은 건너뜁니다.
- 영상 종료 후 진도 반영을 기다리고 필요한 경우 해당 수업의 ‘봤어요’를 누릅니다.
- **완료 수업 수 = 전체 수업 수**이고 퀴즈와 미션도 완료되어야 강좌 완료로 기록합니다. 화면의 반올림된 100%나 단순 영상 종료로 완료를 추정하지 않습니다.
- 자료 수업은 기본적으로 직접 확인하도록 멈춥니다. 설정에서 선택하면 65~600초 대기 후 ‘봤어요’를 누릅니다.
- 객관식 퀴즈는 생성, 선택, 제출, 다음 문항, 결과 확인, 오답 재시도를 자동으로 진행합니다. 섹션의 선행 수업을 완료한 뒤 시작합니다.
- 퀴즈는 정답을 추론하는 AI가 아닙니다. 선택지를 순서대로 시도하고 화면의 정오답 피드백을 저장해 오답을 제외합니다. 섞인 선택지는 내용으로 구분하며, 인프런이 허용한 재시도만 사용합니다. 퀴즈의 제출 완료와 점수 100점은 다릅니다. 재시도를 소진해도 사이트가 제출 완료로 표시하면 완료로 집계합니다.
- 미션은 이미 임시 저장된 제목·본문을 열어 제출할 수 있습니다. 원고 작성, 첨부파일 제작, 강사의 승인까지 자동화하지는 않습니다. 제출 후 검토 대기는 완료로 처리하지 않습니다. 이번 대상 5개 강좌의 목차에는 별도 제출형 미션이 없습니다.
- 라이브 수업은 직접 진행하도록 멈춥니다. 수료증 발급 조건은 별도입니다.
- 자동 재생 차단, 재생 오류, 90초간 영상 정지, 2분간 탭 응답 없음 등을 안내합니다.
- 재생 중에만 화면 절전을 방지할 수 있습니다. 덮개 닫기나 강제 잠자기는 방지할 수 없습니다.

진도 API를 직접 호출하거나 재생 위치를 끝으로 이동하지 않습니다. 실제 플레이어 재생과 화면의 버튼을 사용합니다. `봤어요` 버튼 클릭 간격은 최소 65초입니다.

## 방식 비교와 선택 근거

| 방식 | 이 작업에서의 장점 | 비용·제약 |
| --- | --- | --- |
| Chrome 확장 프로그램 | 기존 로그인 상태 활용, 대기열 UI, 로컬 저장, 한 탭 순차 재생 | 처음 한 번 수동 설치, 사이트 DOM 변경에 대응 필요 |
| Playwright 헤드리스 실행기 | 자동화 테스트와 별도 환경에 적합 | 로그인 프로필 관리, 브라우저 설치, 보호된 플레이어·자동 재생 호환성 확인 필요 |
| 사용자 스크립트 | 작은 다음 버튼 자동화에 간단 | 별도 스크립트 관리자 필요, 여러 강좌 대기열·설정 관리 추가 구현 필요 |

이 사용 방식에는 확장 프로그램을 선택했습니다. 헤드리스 Chromium은 분리된 테스트 환경에서 사용합니다.

공식 문서 및 조사 자료 (2026-09-22 확인):

- [Chrome 콘텐츠 스크립트](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts): 페이지 DOM을 읽고 조작하는 격리된 실행 환경.
- [확장 서비스 워커 수명](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle): 워커는 종료될 수 있으므로 대기열을 `storage.local`에 저장.
- [Chrome 자동 재생 정책](https://developer.chrome.com/blog/autoplay): 음소거 기본값과 재생 거부 처리의 근거.
- [Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms), [power](https://developer.chrome.com/docs/extensions/reference/api/power): 응답 감시와 재생 중 절전 방지.
- [Playwright 확장 테스트](https://playwright.dev/docs/chrome-extensions): 확장이 설치된 별도 Chromium 프로필로 검증.
- [인프런 강사의 진도율 답변](https://www.inflearn.com/community/questions/1818379/진도율): 영상 끝까지 재생 및 일부 수업의 ‘봤어요’ 확인 안내. 인프런 운영팀의 정책 문서는 아닙니다.
- [인프런 공개 강의실](https://www.inflearn.com/course/lecture?courseSlug=virtualization-개발-환경-구축-가이드&unitId=242465)의 배포 JavaScript와 로그인된 강의실에서 목차, 영상 하단 버튼, 진도율 분수, 퀴즈 생성·선택·제출 화면을 확인했습니다.

## 개발과 검증

```sh
npm run check
npm test
npx playwright install chromium
npm run test:e2e
```

E2E는 임시 프로필에서 확장을 설치하고, 인프런 도메인 요청을 테스트용 강의실로 대체합니다. 실제 사용자 계정이나 수강 기록에 접근하지 않습니다. 테스트용 2초 WebM은 `tests/fixtures/lesson.webm`입니다. 실제 미디어의 `play`/`ended`와 확장 메시징·저장소를 사용합니다.

검증 항목: 구형 주소 전환, 비즈 도메인 유지, 두 강좌 순차 재생, 65초 자료 대기, 완료 미반영, 정지·재개, 탭 종료, 보류·재시도, 선택지가 섞이는 퀴즈의 오답 교정, 미션 제출과 검토 대기 구분, 두 테마의 접근성과 320~1280px 배치. [antislop Delivery Gate와 화면 증거](anti-slop/delivery-gate-2026-09-22.md).

- `src/adapter.ts`: 공개 강의실 DOM과 상호작용. 사이트 변경 시 우선 점검할 파일.
- `src/content.ts`: 재생·완료 대기·다음 수업 이동.
- `src/assessments.ts`: 퀴즈 자동 제출·오답 교정·미션 원고 제출.
- `src/background.ts`: 대기열·단일 탭 소유권·영속 저장·응답 감시.
- `src/dashboard.ts`, `public/dashboard.*`: 강좌 목록과 설정.

`npm run build` 후 확장 관리 화면에서 새로고침하면 업데이트됩니다. 현재 재생은 멈춘 뒤 갱신하세요. 버전 업데이트나 브라우저 재시작 후에는 명시적으로 이어 재생해야 합니다.

## 권한과 데이터

`storage`는 대기열·설정·최근 100개 기록·최대 2,000개 퀴즈 정오답 기록, `alarms`는 응답 감시, `power`는 재생 중 절전 방지에 사용합니다. 호스트 권한은 `inflearn.com`, `www.inflearn.com`, `biz.inflearn.com`에 한정합니다. 페이지 URL·제목·진도와 퀴즈 피드백을 로컬에 저장하며 별도 서버, 원격 실행 코드, 쿠키·비밀번호 접근은 사용하지 않습니다.

iframe 안의 별도 출처 플레이어, DRM에 따른 재생 불가, 숨겨진 완료 정보, 사이트 개편에는 추가 대응이 필요할 수 있습니다. 자동화가 정보를 읽지 못하면 완료로 처리하지 않고 확인을 요청합니다.
