루루루 사용 안내

인프런에 로그인한 Chrome에서 강좌를 한 개씩 연속 재생합니다. 수업과 평가의 완료를 확인하면 다음 강좌를 엽니다.

처음 실행하기

  1. 대기열의 ‘인프런 로그인’을 눌러 공식 로그인 페이지에서 로그인하고, 수강 가능한 강좌 주소를 복사합니다. 비밀번호는 확장 프로그램에 입력하지 않습니다.
  2. 대기열에 주소를 한 줄에 하나씩 추가합니다. ‘열린 탭 가져오기’로도 추가할 수 있습니다.
  3. 중복 재생 중인 인프런 강의실을 정리하고 ‘대기열 재생’을 누릅니다.
  4. 새로 열린 재생 탭과 Chrome을 켜 둡니다. 대기열 화면은 닫아도 재생됩니다.

완료와 이어 재생

‘완료 확인’은 사이트에 표시된 수업·퀴즈·미션이 모두 완료되었을 때 표시됩니다. 진행률을 읽지 못하거나 강사의 미션 검토가 남아 있으면 확인이 필요한 상태로 남습니다. 수료증 발급 조건은 별도입니다.

자료 수업은 기본적으로 멈춥니다. 설정에서 ‘봤어요’ 자동 클릭을 선택하면 지정한 시간 후 확인 버튼을 누릅니다. 사이트의 클릭 간격을 고려해 65초 이상을 기다립니다.

퀴즈와 미션

객관식 퀴즈는 선택지를 순서대로 시도하고 화면에 표시된 정오답을 기억합니다. 오답은 다음 시도에서 제외하며 사이트가 제공한 횟수 안에서만 재시도합니다. 정답을 추론하는 방식이 아니므로 첫 시도는 틀릴 수 있습니다. 퀴즈 제출 완료가 점수 100점을 뜻하지는 않습니다.

미션은 임시 저장된 제목과 본문을 열어 제출합니다. 원고가 없거나 첨부 등 필수 항목이 남으면 멈춥니다. 강사의 검토가 필요한 미션은 제출과 완료를 구분합니다.

재생이 멈췄을 때

  • 소리 있는 자동 재생이 차단되면 강의실에서 재생을 한 번 누르거나 음소거를 켭니다.
  • 로그인이 필요하면 ‘인프런 로그인’을 눌러 공식 페이지에서 로그인합니다. 대기열로 돌아와 ‘이어 재생’을 누르면 중단된 강좌를 다시 엽니다.
  • 강의실 주소를 찾지 못했다는 404 오류가 나오면 강좌 행의 ‘주소 수정’에서 실제 강의실 주소를 저장한 뒤 ‘이어 재생’을 누릅니다. 수강 권한이 없는 강좌도 404가 날 수 있으므로 인프런에서 수강 가능 여부를 확인합니다.
  • 해당 강좌를 나중에 처리하려면 ‘이 강좌 보류’를 누릅니다. 완료로 기록하지 않고 다음 강좌를 엽니다.
  • 영상이 끝나도 완료가 반영되지 않으면 ‘봤어요’ 버튼과 목차의 완료 체크를 확인합니다.
  • 브라우저를 다시 시작하면 자동으로 재생하지 않습니다. 저장된 대기열에서 ‘이어 재생’을 누릅니다.

실행 환경

Chrome 120 이상이 필요합니다. 재생 중 절전 방지 옵션은 화면 절전을 막지만 노트북 덮개 닫기, 강제 잠자기, 네트워크 중단까지 막지는 못합니다. 사이트 화면이 변경되거나 보호된 별도 플레이어를 쓰는 강좌에서는 조정이 필요할 수 있습니다.

저장하는 정보

강좌 주소, 제목, 진도, 설정, 최근 재생 기록과 퀴즈 정오답 기록을 이 브라우저의 로컬 확장 저장소에 보관합니다. 확장 프로그램은 별도 서버를 사용하지 않으며 비밀번호나 쿠키를 읽지 않습니다.
